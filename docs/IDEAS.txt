Perspicua Development Ideas
===========================

KERNEL ARCHITECTURE & PERFORMANCE:
  - Demand Paging (On-Demand ELF Loading)
      Difficulty: High | Impact: Very High
      Details: Load 4KB pages from SD on-demand during page faults.
      Benefit: Reduces process startup time and RAM usage significantly.
  - Fully Interrupt-Driven I/O (SD & UART)
      Difficulty: Medium | Impact: High
      Details: Use GIC interrupts to wake blocked tasks instead of polling.
      Benefit: Improves SMP utilization by unblocking the scheduler.
  - Kernel Preemption & Priority Scheduling
      Difficulty: High | Impact: Medium
      Details: Support EL1 preemption and Priority/MLFQ scheduling.
      Benefit: Improves system responsiveness and prevents kernel task lag.
  - Shared Memory IPC (shm)
      Difficulty: Medium | Impact: High
      Details: Support shared physical page frames via mmap(MAP_SHARED).
      Benefit: Enables high-performance graphics and complex IPC.

USER-SPACE & LIBC MATURITY:
  - Standardized Error Handling (errno.h)
      Difficulty: Low | Impact: High
      Details: Implement global errno and update libc syscall wrappers.
      Benefit: Essential for porting 3rd party C libraries and tools.
  - Core POSIX Utilities ("Base System")
      Difficulty: Low-Med | Impact: High
      Details: Implement mkdir, rm, cp, mv, ps, kill, grep, wc, etc.
      Benefit: Transitions the project from experiment to usable system.
  - Shell (sh) Quality of Life
      Difficulty: Medium | Impact: Medium
      Details: Add tab completion, globbing (*), and job control (fg, bg).
      Benefit: Exponentially improves interactive developer experience.
  - User-Space System Integrity
      Difficulty: Medium | Impact: High
      Details: Implement assert.h and a user-space libc test suite.
      Benefit: Ensures libc stability as complexity moves to user-land.

TOOLING & WORKFLOW IMPROVEMENTS (RESOLVED):
  - Incremental SD Card Updates: [RESOLVED] SD image is created once, then
      mcopy -o incrementally overwrites only changed .elf files.
  - GDB Python Helper Scripts: [RESOLVED] scripts/gdb_helpers.py provides
      tasks, ps, pagetable <pid>, and irqstats commands. Auto-loaded by
      the gdb target.
  - Configurable Features: [RESOLVED] CMake options CONFIG_SMP,
      CONFIG_LOCKDEP, CONFIG_NR_CPUS. Toggle via:
      just config_smp=OFF config_lockdep=OFF build
  - Network TAP Setup: [RESOLVED] just net-setup / net-teardown / run-net
      with platform-specific (macOS/Linux) TAP/bridge automation.

LONG-TERM STRATEGIC IDEAS:
  - POSIX ABI Compatibility: Align syscall numbers with Linux/AArch64.
  - Graphics Server: Wayland-lite compositor designed for user-space.
  - Virtualization: Use EL2 extensions for hardware-assisted guest OS.

HIDDEN RISKS & WARNINGS (RESOLVED):
  - Polled I/O Deadlock: [RESOLVED] SD driver now uses spin_lock_irqsave to
      serialize all SDHCI controller access across cores. UART TX was already
      protected by uart_tx_lock; UART RX is interrupt-driven via TTY.
  - Privilege Escalation: [RESOLVED] All user-space memory access uses
      ldtrb/sttrb (uaccess.S) with validate_user_buffer() and exception fixup.
      All 27 syscalls go through copy_from_user/copy_to_user.
  - FAT32 Integrity: [RESOLVED] Block cache now flushes dirty entries on LRU
      eviction. Added block_cache_sync() and SYS_SYNC syscall for explicit
      writeback from userspace.
